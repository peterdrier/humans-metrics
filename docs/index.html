Cross-section score by section

Which number to watch: the raw edge count tracks how much wiring exists, density tracks whether the wiring is growing faster than the module count. After a split the raw count rises by construction (more modules) while density should fall; density is the one that says whether boundaries are holding.

Who does the work

Every non-merge commit on main is one PR (squash merges). Each is credited to its author, never the merger, and sorted into a lane by collect/lanes.yml: automation is scheduled maintenance nobody prompted (section doctor, debt sweep, freshness sweep, codex nightly, dependabot); the rest is Peter or others by PR author. Shares are over a rolling 28-day window so a quiet day does not swing to 100%.
